# 넷마루 (NetMaru)

한국어로 사용하는 macOS 네트워크·서버 관리 도구입니다. SSH 연결, 파일 전송, 서브넷 계산과 네트워크 진단을 한곳에서 사용할 수 있습니다.

이 저장소는 **설치파일과 사용 안내만 제공**합니다. 소스코드와 개인 설정, SSH 키파일은 포함하지 않습니다.

## 다운로드·설치

**[최신 설치파일 다운로드 — Apple Silicon](https://github.com/kkt9102/NetMaru/releases/latest/download/NetMaru-arm64.pkg)**

[모든 Releases](https://github.com/kkt9102/NetMaru/releases) · [공개 Packages](https://github.com/users/kkt9102/packages/container/package/netmaru) · [Packages 사용법](PACKAGES.md) · [개인정보 처리 안내](PRIVACY.md) · [MIT License](LICENSE)

- 지원 환경: Apple Silicon(M 시리즈), macOS 14 이상
- `NetMaru-arm64.pkg`를 실행하고 설치를 진행하세요. 관리자 승인 후 `/Applications/NetMaru.app`에 설치합니다.
- 기존 `/Applications/NetMaru.app`은 새 버전으로 교체하고 저장된 연결·설정·계산 기록은 유지합니다.
- DMG 형식이 필요하면 DMG 안의 `NetMaru.pkg`를 실행해 같은 방식으로 설치합니다. ZIP은 수동 설치용 앱입니다.
- 기존 NetMaru가 실행 중이라면 종료한 뒤 새 앱을 실행하세요.
- 로컬 임시 서명된 개인용 배포본입니다. 개발자 인증서 서명과 Apple 공증은 되어 있지 않아 macOS가 실행을 제한할 수 있습니다.
- Intel Mac, iPhone, iPad용 배포본은 제공하지 않습니다.

### 파일 무결성 확인

각 Release의 `SHA256SUMS`와 다운로드한 설치파일의 값을 비교하세요. 저장소의 [SHA256SUMS](SHA256SUMS)는 `downloads/`에 보관한 버전별 파일용입니다.

```sh
shasum -a 256 NetMaru-arm64.pkg
```

## 창을 닫은 뒤 다시 열기

창의 닫기 버튼이나 ⌘W는 창만 닫습니다. 앱이 Dock에 남아 있다면 아이콘을 눌러 기본 창을 다시 열 수 있습니다. 앱의 **파일 → 넷마루 창 열기(⌘0)**로도 다시 열 수 있습니다. 설정 창만 열린 상태에서도 기본 창을 복원합니다. ⌘Q는 앱을 완전히 종료합니다.

업데이트 설치 시 실행 중인 앱은 먼저 종료해야 합니다. Installer가 종료를 안내하며, 앱을 강제로 종료하거나 다운로드만으로 자동 실행하지 않습니다. 다른 폴더에 있는 앱 복사본은 자동 삭제하지 않습니다.

## 실시간 그래프 사용

1. **네트워크 모니터**를 엽니다. 다운로드·업로드 전송량은 1초 간격으로 관측합니다.
2. 인터페이스를 자동 또는 수동으로 선택하고 **B/s·Mbps** 단위를 전환할 수 있습니다.
3. 핑 대상 호스트와 측정 주기·방식을 설정한 뒤 **핑 시작**을 누릅니다.
4. 호스트별 그래프에서 최근 120회의 현재·최소·평균·최대 지연과 손실률을 확인합니다. 실패는 빨간 표시와 끊긴 선으로 나타납니다.

트래픽 그래프는 **선택한 인터페이스 한 개의 실제 전송량**입니다. 인터넷 최대 속도 측정값이 아니며 LAN·VPN 트래픽이 포함될 수 있습니다. 관측 합계는 시작 또는 인터페이스 변경 이후 기준입니다. 트래픽 관측을 일시정지·재시작할 수 있고, 모니터 화면을 벗어나면 관측을 중지합니다. 그래프 기록은 메모리에만 보관합니다.

여러 호스트는 병렬로 측정합니다. 응답이 늦으면 설정한 주기보다 다음 측정이 지연될 수 있습니다. 실패한 핑은 장치의 전원 꺼짐을 의미하지 않습니다.

## SSH 키파일 설정

1. **SSH 클라이언트 → 연결 추가(+)**를 누릅니다.
2. 표시 이름, 호스트/IP, 포트, 사용자 이름을 입력합니다.
3. 필요하면 **키파일(선택) → 파일 선택**에서 개인키를 선택합니다. `.pub` 공개키는 선택하지 않습니다.
4. 저장한 연결을 선택하고 **연결**을 누릅니다.
5. 처음 연결하는 서버의 지문을 확인하고, 비밀번호나 키 암호는 터미널 프롬프트에서 입력합니다.

키파일을 선택하지 않으면 OpenSSH의 기본 설정·에이전트·비밀번호 인증을 사용합니다. 키파일을 선택하면 해당 키로 인증하며, 실패해도 비밀번호 인증으로 자동 전환하지 않습니다.

키파일 내용과 비밀번호·키 암호·터미널 출력의 로그 파일은 만들지 않습니다. 연결 정보, 키파일 경로, 계산 기록은 해당 맥의 환경설정에 **암호화 없이** 저장합니다. 네트워크 진단은 지정한 대상이나 DNS 제공업체에 직접 통신하며 상대 서버가 공인 IP와 질의를 기록할 수 있습니다. 알림·클립보드·시스템 Terminal 기록의 범위도 [개인정보 처리 안내](PRIVACY.md)에 설명했습니다.

## 현재 범위와 제한

- 독립적으로 작성한 macOS 앱입니다. 다른 앱의 공식 한국어 버전이나 원본 소스를 복원한 재빌드가 아닙니다.
- 내장 터미널은 120×34 고정 크기의 기본 VT 화면입니다. 복잡한 vim/tmux 작업 등에는 **시스템 터미널** 버튼을 사용하세요. 모든 ANSI 제어, 전각 문자 배치와 한글 입력기 동작을 보장하지 않습니다.
- Unix 계열 서버의 SFTP 목록은 `ls -la --`로 조회합니다. Windows 서버에서는 SFTP 터미널의 `ls`를 사용하세요. 특수한 파일명·경로와 서버별 설정에는 제한이 있습니다.
- 서버 대시보드는 대상 운영체제의 명령어와 권한에 의존합니다. Windows 서버에는 PowerShell이 필요합니다.
- LAN 검색은 TCP 응답과 ARP 캐시 기반입니다. 응답하지 않거나 격리된 장치는 놓칠 수 있고, 오래된 ARP 항목이 포함될 수 있습니다.
- HTTP 검사는 HEAD 요청을 사용합니다. TLS 검사 결과는 OpenSSL 신뢰 저장소 기준으로 브라우저와 다를 수 있습니다.
- 위젯과 ISP 자동 식별은 포함하지 않습니다.

## 검증 상태

- 계산·입력 검증 등 핵심 테스트 14개와 앱 통합·수명주기 테스트 12개, 총 **26개 통과**.
- 실제 PTY 입력·출력, 로컬 TCP 배너, 임시 로컬 SSH 서버의 키 인증 및 SFTP 업로드·다운로드·삭제 확인.
- 창 재열기 요청·설정 창 예외·반복 재열기·종료 정리 회귀 테스트 4개 통과. 실제 Dock 클릭을 통한 UI 조작은 미검증입니다.
- 64비트 카운터·측정 간격·인터페이스 변경·핑 손실률 계산, 실제 macOS 카운터 조회 및 예시 데이터 그래프 렌더링 확인.
- 설치 보호 테스트 6개 추가 통과: 신규·기존·상위 버전·다른 앱·실행 중·설치 경로 검사. 실제 관리자 설치는 수행하지 않았습니다.
- Apple Silicon Release 빌드, PKG 페이로드·설치 스크립트·로컬 코드 서명 및 DMG 무결성 확인.
- 공개 배포 전 실행파일의 로컬 디버그 경로를 제거하고 재서명했습니다.
- 실제 사용자 서버, 암호화된 키, 비밀번호 인증, 서버별 지표·알림·장치 깨우기 등은 추가 확인이 필요합니다. GUI 시각·조작 검증은 완료하지 않았습니다.
